# Identidade visual FireWatch

Vetores exportados do Brand Board Firewatch. Os símbolos e wordmarks preservam os desenhos, cores e proporções dos arquivos de origem.

| Pasta | Uso |
| --- | --- |
| `symbols/` | Símbolo Ember para fundos claros/escuros; Charcoal sobre Ember; gradiente apenas no destaque de abertura |
| `wordmarks/` | Assinatura Charcoal sobre fundo claro e Ash sobre fundo escuro |
| `logos/` | Composições horizontais: principal, fundo escuro e fundo Ember |
| `app-icons/` | Ícones completos com o símbolo centralizado sobre os fundos Ember, Charcoal e branco |

As composições horizontais alinham o símbolo de 38×58 e o wordmark de 214×35 ao centro, com 16 unidades de respiro. Os ícones centralizam o símbolo exportado de 43×66 sobre o fundo original. Nunca esticar, girar, recolorir ou usar gradiente no wordmark. Mínimos: símbolo com 24 px de altura e assinatura completa com 96 px de largura.
